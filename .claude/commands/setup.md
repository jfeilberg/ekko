---
description: Walk through ekko's first-time setup
---

Run `npx create-ekko-agent <project-name>` to scaffold a working bot from scratch. The CLI handles cloning, dependency install, Vercel link, Slack app creation, OAuth install, env var writeback, and deploy.

If the user has already cloned ekko and just needs to set it up, run `pnpm bootstrap` from inside their repo instead.
